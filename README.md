# Hello, World! 👋
Моя первая программа на Python. С неё начался мой путь в программирование.
## Что делает программа
Выводит на экран приветствие `Hello, World!`.
## Как запустить
1. Установите [Python 3](https://www.python.org/downloads/)
2. Скачайте файл `main.py`
3. Откройте терминал в папке с файлом и выполните:
   python main.py
